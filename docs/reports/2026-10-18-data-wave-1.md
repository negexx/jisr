## STEP 1 — the `minorUnitDigits` code fix

**Already landed upstream; no new code change was needed.** Commit `05402d50` — *"fix: import
tooling uses the currency's minor-unit digits (HUF is whole forints)"* — is an ancestor of the base
`f0cc00ef`. It changed exactly the spots the `data/README.md` follow-up names:

- `scripts/import/scholarships.ts` — `toMinor(amount.min/max, currency)` for support amounts;
- `scripts/import/evidence.ts` — `fromMinor(amountMinor, currency)` in `checkFeeAmount` and
  `checkTuitionRange`;
- `scripts/import/checker.ts` — `fromMinor(...)` in `claimText`;
- `scripts/import/reader.ts` — the prompt now reads *"EUR in hundredths: EUR 14,650 = 1465000; HUF
  has no minor unit: HUF 1,500,000 = 1500000"*;
- plus `scripts/import/enrich-fr.ts` and the new helper `scripts/import/money.ts`.

Verification this wave:

## Promote — not run

`data:promote` has **no `--dry-run` flag**; `pnpm data:promote --dry-run` refuses with exit 2
(`--confirm-human-read is required`) and promotes nothing. After the owner fills `AUDIT.csv` and the
batch passes, the exact commands are:

```
pnpm data:audit status
pnpm data:promote --confirm-human-read --verified-on <YYYY-MM-DD> --audited-batch --replace-revisions
pnpm data:check
```

`--replace-revisions` is required: the 89 records are enrichments of records already in `data/`.

# Italy as a destination Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add Italy (Bachelor, Computer Science / Engineering / Business-Economics, English-taught first) with the same trust model and vertical slices as Hungary. Spec: `docs/superpowers/specs/2026-10-04-italy-hungary-design.md` (Italy section, Slices 2-3) and the owner brief of 2026-10-05 (scope, regional aid, owner checkpoints). Pattern to repeat: `docs/superpowers/plans/2026-10-04-hungary-slice1.md`. Branch `feat/italy` from `origin/main` (PR #12 merged).

**Architecture:** `scripts/import/sources/mur.ts` reads two MUR open-data CSVs (offer of degree courses, list of universities) into staged institutions and programmes (`pnpm data:import italy`). The CSVs give name, university, town, degree class and language, but no programme URL and no university website, so the programme page, the institution website and every fee/deadline come from `data:pages --search`, `data:inst-proposals`, then the existing reader + checker + audit + promote path. National facts (route, channels, pre-enrolment calendar) come from the Universitaly page of the MUR "Procedure" note.

**Tech Stack:** TypeScript strict, Vitest (inline CSV fixtures, no network), existing `scripts/import/*`.

## Global Constraints

- Official sources only; a model proposes, code decides; every fact needs a verbatim quote that code re-fetches; unknown stays unknown; an official value is never overwritten.
- Nothing in `data/` by hand except owner-approved decisions: the skeleton (country, channels, route) is committed for the owner to approve in the PR; programmes, institutions and scholarships enter only through the audit sample and `pnpm data:promote`.
- Route `ma-bac-to-it` outcome is `check`: the MUR note is general (12 years of schooling, institutions evaluate), it does not name the Moroccan Bac. Never invent an outcome.
- Scope: Bachelor (`TipoCorso` = `Laurea`), English-taught (`LINGUA` = `Inglese`); mixed `Italiano - Inglese` programmes are counted and reported, not staged, until the owner decides. Italian-taught is a later batch with Italian B2 rules.
- Latest academic year in the file only (2025, i.e. 2025/26; the 2026/27 offer is not published yet: say so in the review notes).
- Field is decided by degree class (code), never by the model: L-31 computer-science; L-8, L-9, L-7, L-23 engineering; L-18, L-33 business-economics; L-41 business-economics, always low confidence. Low confidence also when `classifyDaad(name)` points to another field.
- Distance learning (`DIDATTICA` = `Teledidattica` or `Prevalentemente a distanza`) is left out: a study visa needs in-person attendance. Count them.
- Slugs: `it-<name40>-<city>` for institutions (a name collision throws), `<inst>-<name24>-<class>` for programmes (class lower-cased without hyphen: `l18`).
- Licences: MUR open data is IODL 2.0 (attribution required): add it to the source-licence table in `data/README.md`.
- Fees keep the currency the page states (EUR); never converted. Italian fees are per university: a range or a table by ISEE band is unknown.
- Keys only in `.env.local`, never read or printed. Serper about 1,614 credits: always `--max-queries`, announce the planned number first. Reader/checker prices and off-peak rule as in the brief.
- Tests use temp dirs; no `any`, `@ts-ignore`, non-null `!`; explicit `git add` paths; conventional commits ending with `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`.
